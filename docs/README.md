# Documentación técnica

Este directorio contiene la documentación de diseño, decisiones y seguridad del proyecto Decide Nicaragua.

## ¿Qué encontrarás aquí?

- `VISION.md` — mapa del ecosistema completo (filosofía → doctrina → vehículos → ejecución), tensiones estratégicas y foco actual.
- `ARCHITECTURE.md` — descripción de alto nivel de la arquitectura, componentes, modelo de datos y flujo de autenticación.
- `DECISIONS.md` — registros de decisiones técnicas (ADRs) que explican por qué se eligieron las tecnologías y patrones actuales.
- `SECURITY.md` — modelo de amenazas, controles implementados, checklist de seguridad y procedimientos de respuesta a incidentes.
- `ROADMAP.md` — estado de desarrollo, fases completadas y prioridades para las próximas iteraciones.
- `ESTUDIO-VIDEO.md` — diseño consolidado del módulo de estudio de video con clones digitales para comunicación política (ADR-017): arquitectura, modelo de datos, pipeline, seguridad y plan de implementación.

## Uso recomendado

1. Comienza con `ARCHITECTURE.md` para entender la estructura general del sistema.
2. Lee `DECISIONS.md` para conocer las razones detrás de las elecciones técnicas.
3. Revisa `SECURITY.md` antes de cualquier despliegue o cambio de infraestructura.
4. Consulta `ROADMAP.md` para ver qué ya está implementado y qué falta completar.

## Contribuciones a la documentación

- Si añades un nuevo documento técnico, agrega una referencia aquí.
- Actualiza las fechas y el estado de los documentos cuando haya cambios significativos en la arquitectura, la seguridad o el roadmap.
- Mantén la documentación corta, clara y alineada con el estado actual del código.
