# Plan 2 — Foros, propuestas formales y consensos públicos

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que cada comunidad (territorio de origen, comunidad de acogida y la comunidad general de toda la plataforma) tenga foros con temas, respuestas y señales; que un tema pueda convertirse en propuesta formal con plazo de deliberación y votación; que al cerrarse se publique su consenso (conclusión, señales y objeciones de la minoría) para cualquier visitante; y que la mesa pueda moderar con motivo registrado y apelación.

**Architecture:** Se construye sobre el módulo `deliberation` existente (propuestas, comentarios y señales por grupo). Se agrega el contenedor `Forum` (por grupo; uno por defecto, creado al vuelo), una comunidad «general» (grupo `custom` con slug `general`) a la que entra todo miembro verificado, campos nuevos en `Proposal` (tipo, foro, plazo, votación, conclusión, objeciones, oculto) y `ProposalComment` (oculto), y la tabla `moderation_actions`. Módulo nuevo `forums` (foros, conversión a propuesta, apertura de votación, cierre con consenso, moderación, consensos públicos). La web suma «Foros», la página de cada foro, las acciones nuevas en la página del tema y la cola de apelaciones en «Mesa».

**Tech Stack:** NestJS 10, Prisma 6 + PostgreSQL, vitest 3, Next.js 15, pnpm 9 + Turborepo.

**Spec:** `docs/superpowers/specs/2026-11-01-primeros-200-design.md` (§3 visitantes y coordinadores, §5 comunidades, §7 foros y propuestas, §9 auditoría). Plan anterior y sus pendientes: `docs/superpowers/plans/2026-11-01-plan-1-base.md`, `docs/superpowers/plans/2026-11-01-plan-1-pendientes.md`.

## Global Constraints

- Solo participa quien es miembro del grupo (regla vigente del plan 1: las membresías existen solo para `verified_citizen`). Todo endpoint de escritura usa la verificación de membresía existente.
- Comunidad general: grupo `type = custom`, `slug = 'general'`, `name = 'Toda la comunidad'`. Todo miembro verificado entra al verificarse (vía `GroupsService.syncMemberships`) y sale al ser suspendido (la suspensión ya borra todas las membresías).
- Cada grupo tiene un foro por defecto (`isDefault = true`, título «Foro de <nombre del grupo>»), creado al vuelo la primera vez que se listan los foros del grupo. Los temas viejos sin foro se asignan a ese foro en la migración.
- Crear foros adicionales: solo la mesa (cualquier cargo con titular verificado, `BoardService.roleOf`). El plan 3 extiende esto a los coordinadores de cada comunidad mediante `ForumsService.canModerate(profileId, groupId)` (única función de permiso a extender).
- Moderar (ocultar y restaurar): mismos permisos que crear foros (`canModerate`). Ocultar exige motivo (10–500 caracteres). El autor puede apelar una vez (10–1000 caracteres); la mesa resuelve. Todo queda auditado.
- Contenido oculto: la API devuelve `hidden: true`, `body: ''` y el motivo; nunca el texto original (salvo a la mesa en la cola de apelaciones).
- Tema → propuesta formal: el autor o quien puede moderar; fija `deliberationEndsAt = ahora + DELIBERATION_DAYS` (constante 7; el plan 3 la vuelve regla votable).
- Abrir votación: solo después de `deliberationEndsAt`, el autor o quien puede moderar; crea una elección en el mismo grupo con 3 opciones en este orden: «A favor», «En contra», «Abstención»; dura `VOTING_DAYS = 7`; la crea a nombre de quien la abre (así puede contarla con el endpoint existente).
- Cerrar con consenso: el autor o quien puede moderar; exige conclusión (10–2000 caracteres); objeciones de la minoría opcionales (hasta 2000). Ya no se cierra con `PATCH status`.
- Consensos públicos: `GET /api/public/consensos` sin sesión. Devuelve solo temas cerrados con conclusión y no ocultos: título, nombre de la comunidad, tipo, conclusión, objeciones, conteo de señales, fecha de cierre y, si hubo votación contada, la opción ganadora. Nunca nombres de autores ni de quienes comentaron.
- Mensajes nuevos en español; textos con tildes escritos solo con las herramientas Edit/Write y verificados en UTF-8 estricto.
- Cada acción nueva escribe un evento de auditoría sin datos personales en `metadata`.
- Commits con la línea final `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Un tema oculto que siga mostrando su texto por algún camino (lista, detalle, consensos públicos, comentarios).
2. Alguien que no es miembro del grupo creando temas en un foro de ese grupo, o en un foro de otro grupo pasando un `forumId` ajeno.
3. Abrir votación antes de que termine el plazo de deliberación, o dos veces para el mismo tema.
4. El endpoint público devolviendo un nombre (autor, comentarista) o un tema no cerrado.
5. Un miembro suspendido o un visitante moderando o apelando contenido ajeno.

```sql
-- Comunidad general (grupo custom con slug 'general').
INSERT INTO "groups" ("id", "name", "slug", "type", "description", "isActive", "createdAt", "updatedAt")
SELECT gen_random_uuid(), 'Toda la comunidad', 'general', 'custom',
       'Comunidad de todas las personas verificadas de Nicaragua Decide', true, now(), now()
WHERE NOT EXISTS (SELECT 1 FROM "groups" WHERE "slug" = 'general');

-- Todas las personas verificadas entran a la comunidad general.
INSERT INTO "group_memberships" ("id", "groupId", "profileId", "joinedAt")
SELECT gen_random_uuid(), g."id", p."id", now()
FROM "profiles" p
JOIN "users" u ON u."id" = p."userId"
CROSS JOIN (SELECT "id" FROM "groups" WHERE "slug" = 'general') g
WHERE u."status" = 'verified_citizen'
ON CONFLICT ("groupId", "profileId") DO NOTHING;

-- Un foro por defecto para cada grupo que ya tenga temas, y los temas viejos pasan a él.
INSERT INTO "forums" ("id", "groupId", "title", "isDefault", "createdAt")
SELECT gen_random_uuid(), gr."id", 'Foro de ' || gr."name", true, now()
FROM "groups" gr
WHERE EXISTS (SELECT 1 FROM "proposals" pr WHERE pr."groupId" = gr."id")
  AND NOT EXISTS (SELECT 1 FROM "forums" f WHERE f."groupId" = gr."id" AND f."isDefault");

UPDATE "proposals" pr
SET "forumId" = f."id"
FROM "forums" f
WHERE f."groupId" = pr."groupId" AND f."isDefault" AND pr."forumId" IS NULL;
```

import {
  BadRequestException,
  ConflictException,
  ForbiddenException,
  Injectable,
  NotFoundException,
} from '@nestjs/common';
import {
  DELIBERATION_DAYS,
  VOTING_DAYS,
  type ForumDetail,
  type ForumSummary,
  type ModerationAppeal,
  type ProposalSummary,
} from '@decide/shared';
import { PrismaService } from '../prisma/prisma.service';
import { AuditService } from '../audit/audit.service';
import { BoardService } from '../board/board.service';
import type { CreateForumDto } from './dto/create-forum.dto';
import type { CloseTopicDto } from './dto/close-topic.dto';
import type { ModerateDto } from './dto/moderate.dto';

const DIA_MS = 86_400_000;

@Injectable()
export class ForumsService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly audit: AuditService,
    private readonly board: BoardService,
  ) {}

  // ─── Permisos ─────────────────────────────────────────────────────────────

  /**
   * Quién puede crear foros y moderar en un grupo. Plan 2: la mesa directiva
   * (titular verificado). El plan 3 agrega a los coordinadores de la comunidad.
   */
  async canModerate(profileId: string, _groupId: string): Promise<boolean> {
    return (await this.board.roleOf(profileId)) !== null;
  }

  private async esMesa(profileId: string): Promise<boolean> {
    return (await this.board.roleOf(profileId)) !== null;
  }

  private async requireMembership(groupId: string, profileId: string): Promise<void> {
    const m = await this.prisma.groupMembership.findUnique({
      where: { groupId_profileId: { groupId, profileId } },
    });
    if (!m) throw new ForbiddenException('Solo los miembros de esta comunidad pueden participar.');
  }

  private async actorId(profileId: string): Promise<{ actorId: string } | Record<never, never>> {
    const p = await this.prisma.profile.findUnique({ where: { id: profileId }, select: { userId: true } });
    return p?.userId ? { actorId: p.userId } : {};
  }

  // ─── Foros ────────────────────────────────────────────────────────────────

  async listMine(profileId: string): Promise<ForumSummary[]> {
    const memberships = await this.prisma.groupMembership.findMany({
      where: { profileId },
      include: { group: true },
    });
    const result: ForumSummary[] = [];
    for (const m of memberships) {
      await this.ensureDefault(m.groupId, m.group.name);
      const forums = await this.prisma.forum.findMany({
        where: { groupId: m.groupId },
        include: { _count: { select: { proposals: true } } },
        orderBy: [{ isDefault: 'desc' }, { createdAt: 'asc' }],
      });
      for (const f of forums) {
        result.push({
          id: f.id,
          groupId: f.groupId,
          groupName: m.group.name,
          title: f.title,
          description: f.description,
          isDefault: f.isDefault,
          topicCount: f._count.proposals,
        });
      }
    }
    return result;
  }

  private async ensureDefault(groupId: string, groupName: string): Promise<void> {
    const existing = await this.prisma.forum.findFirst({ where: { groupId, isDefault: true } });
    if (!existing) {
      await this.prisma.forum.create({ data: { groupId, title: `Foro de ${groupName}`, isDefault: true } });
    }
  }

  async getForum(profileId: string, forumId: string): Promise<ForumDetail> {
    const forum = await this.prisma.forum.findUnique({
      where: { id: forumId },
      include: { group: true, _count: { select: { proposals: true } } },
    });
    if (!forum) throw new NotFoundException('Foro no encontrado');
    await this.requireMembership(forum.groupId, profileId);

    const topics = await this.prisma.proposal.findMany({
      where: { forumId },
      include: {
        author: { select: { displayName: true } },
        signals: { select: { signal: true } },
        _count: { select: { comments: true } },
      },
      orderBy: { createdAt: 'desc' },
    });

    return {
      id: forum.id,
      groupId: forum.groupId,
      groupName: forum.group.name,
      title: forum.title,
      description: forum.description,
      isDefault: forum.isDefault,
      topicCount: forum._count.proposals,
      canModerate: await this.canModerate(profileId, forum.groupId),
      topics: topics.map((t): ProposalSummary => {
        const counts = { support: 0, neutral: 0, object: 0 };
        for (const s of t.signals) counts[s.signal as keyof typeof counts] += 1;
        return {
          id: t.id,
          groupId: t.groupId,
          forumId: t.forumId,
          title: t.hidden ? 'Tema oculto por moderación' : t.title,
          status: t.status as unknown as ProposalSummary['status'],
          kind: t.kind as unknown as ProposalSummary['kind'],
          hidden: t.hidden,
          authorDisplayName: t.author.displayName,
          signalCounts: counts,
          commentCount: t._count.comments,
          createdAt: t.createdAt.toISOString(),
        };
      }),
    };
  }

  async createForum(profileId: string, dto: CreateForumDto, ip: string): Promise<{ id: string }> {
    if (!(await this.canModerate(profileId, dto.groupId))) {
      throw new ForbiddenException('Solo la mesa directiva puede abrir foros por ahora.');
    }
    const group = await this.prisma.group.findUnique({ where: { id: dto.groupId } });
    if (!group) throw new NotFoundException('Comunidad no encontrada');
    const forum = await this.prisma.forum.create({
      data: {
        groupId: dto.groupId,
        title: dto.title,
        description: dto.description ?? null,
        createdByProfileId: profileId,
      },
    });
    void this.audit.log({
      ...(await this.actorId(profileId)),
      action: 'forum.created',
      resource: `forum:${forum.id}`,
      ip,
      metadata: { groupId: dto.groupId },
    });
    return { id: forum.id };
  }

  // ─── Propuesta formal, votación y consenso ────────────────────────────────

  private async topicForAction(profileId: string, topicId: string) {
    const topic = await this.prisma.proposal.findUnique({ where: { id: topicId } });
    if (!topic) throw new NotFoundException('Tema no encontrado');
    if (topic.hidden) throw new BadRequestException('Este tema está oculto por moderación.');
    const esAutor = topic.authorProfileId === profileId;
    if (!esAutor && !(await this.canModerate(profileId, topic.groupId))) {
      throw new ForbiddenException('Solo quien abrió el tema o la moderación pueden hacer esto.');
    }
    return topic;
  }

  async formalize(profileId: string, topicId: string, ip: string): Promise<void> {
    const topic = await this.topicForAction(profileId, topicId);
    if ((topic.kind as string) === 'propuesta') throw new ConflictException('Este tema ya es una propuesta formal.');
    if ((topic.status as string) !== 'open') throw new BadRequestException('Solo un tema abierto puede convertirse en propuesta.');
    await this.prisma.proposal.update({
      where: { id: topicId },
      data: { kind: 'propuesta', deliberationEndsAt: new Date(Date.now() + DELIBERATION_DAYS * DIA_MS) },
    });
    void this.audit.log({ ...(await this.actorId(profileId)), action: 'proposal.formalized', resource: `proposal:${topicId}`, ip });
  }

  async openVote(profileId: string, topicId: string, ip: string): Promise<{ electionId: string }> {
    const topic = await this.topicForAction(profileId, topicId);
    if ((topic.kind as string) !== 'propuesta') throw new BadRequestException('Primero hay que convertir el tema en propuesta formal.');
    if (topic.electionId) throw new ConflictException('La votación de esta propuesta ya está abierta.');
    if (!topic.deliberationEndsAt || topic.deliberationEndsAt.getTime() > Date.now()) {
      throw new BadRequestException('La votación se abre cuando termina el plazo de deliberación.');
    }
    const ahora = new Date();
    const election = await this.prisma.$transaction(async (tx) => {
      const e = await tx.election.create({
        data: {
          groupId: topic.groupId,

        where: { id: dto.targetId },
        include: { proposal: { select: { groupId: true } } },

      groupId = c.proposal.groupId;
    }
    if (!(await this.canModerate(profileId, groupId))) {
      throw new ForbiddenException('No tienes permiso para moderar en esta comunidad.');
    }
    if (dto.target === 'tema') {
      await this.prisma.proposal.update({ where: { id: dto.targetId }, data: { hidden: true } });
    } else {
      await this.prisma.proposalComment.update({ where: { id: dto.targetId }, data: { hidden: true } });
    }
    const action = await this.prisma.moderationAction.create({
      data: { target: dto.target, targetId: dto.targetId, reason: dto.reason, moderatorProfileId: profileId },
    });
    void this.audit.log({

      action: 'moderation.hidden',
      resource: `${dto.target}:${dto.targetId}`,
      ip,
      metadata: { moderationId: action.id },

  async appeal(profileId: string, moderationId: string, text: string, ip: string): Promise<void> {
    const action = await this.prisma.moderationAction.findUnique({ where: { id: moderationId } });
    if (!action) throw new NotFoundException('Moderación no encontrada');
    const autor = await this.authorOf(action.target as 'tema' | 'respuesta', action.targetId);
    if (autor !== profileId) throw new ForbiddenException('Solo quien escribió el contenido puede apelar.');
    if ((action.status as string) !== 'oculto') throw new ConflictException('Esta moderación ya fue apelada o resuelta.');
    await this.prisma.moderationAction.update({
      where: { id: moderationId },
      data: { status: 'apelado', appealText: text, appealedAt: new Date() },
    });
    void this.audit.log({ ...(await this.actorId(profileId)), action: 'moderation.appealed', resource: `moderation:${moderationId}`, ip });
  }

  async listAppeals(profileId: string): Promise<ModerationAppeal[]> {
    if (!(await this.esMesa(profileId))) throw new ForbiddenException('Solo la mesa directiva resuelve apelaciones.');
    const actions = await this.prisma.moderationAction.findMany({
      where: { status: 'apelado' },
      orderBy: { appealedAt: 'asc' },
    });
    const result: ModerationAppeal[] = [];
    for (const a of actions) {
      result.push({
        id: a.id,
        target: a.target as 'tema' | 'respuesta',
        targetId: a.targetId,
        reason: a.reason,
        appealText: a.appealText ?? '',
        originalText: await this.textOf(a.target as 'tema' | 'respuesta', a.targetId),
        appealedAt: (a.appealedAt ?? a.createdAt).toISOString(),
      });
    }
    return result;
  }

  async resolveAppeal(profileId: string, moderationId: string, restore: boolean, ip: string): Promise<void> {
    if (!(await this.esMesa(profileId))) throw new ForbiddenException('Solo la mesa directiva resuelve apelaciones.');
    const action = await this.prisma.moderationAction.findUnique({ where: { id: moderationId } });
    if (!action) throw new NotFoundException('Moderación no encontrada');
    if ((action.status as string) !== 'apelado') throw new BadRequestException('Esta moderación no tiene una apelación pendiente.');
    if (restore) {
      if ((action.target as string) === 'tema') {
        await this.prisma.proposal.update({ where: { id: action.targetId }, data: { hidden: false } });
      } else {
        await this.prisma.proposalComment.update({ where: { id: action.targetId }, data: { hidden: false } });
      }
    }
    await this.prisma.moderationAction.update({
      where: { id: moderationId },
      data: { status: restore ? 'restaurado' : 'confirmado', resolvedAt: new Date() },
    });
    void this.audit.log({
      ...(await this.actorId(profileId)),
      action: restore ? 'moderation.restored' : 'moderation.confirmed',
      resource: `moderation:${moderationId}`,
      ip,
    });
  }

  private async authorOf(target: 'tema' | 'respuesta', id: string): Promise<string | null> {
    if (target === 'tema') {
      return (await this.prisma.proposal.findUnique({ where: { id } }))?.authorProfileId ?? null;
    }
    return (await this.prisma.proposalComment.findUnique({ where: { id } }))?.authorProfileId ?? null;
  }

  private async textOf(target: 'tema' | 'respuesta', id: string): Promise<string> {
    if (target === 'tema') {
      const t = await this.prisma.proposal.findUnique({ where: { id } });
      return t ? `${t.title}\n\n${t.body}` : '';
    }
    return (await this.prisma.proposalComment.findUnique({ where: { id } }))?.body ?? '';
  }
}

  async publicConsensus(): Promise<PublicConsensus[]> {
    const topics = await this.prisma.proposal.findMany({
      where: { status: 'closed', hidden: false, conclusion: { not: null } },
      select: {
        id: true, title: true, kind: true, conclusion: true, objections: true, closedAt: true, electionId: true,
        group: { select: { name: true } },
        signals: { select: { signal: true } },
      },
      orderBy: { closedAt: 'desc' },
      take: 100,
    });
    const result: PublicConsensus[] = [];
    for (const t of topics) {
      const counts = { support: 0, neutral: 0, object: 0 };
      for (const s of t.signals) counts[s.signal as keyof typeof counts] += 1;
      let winningOption: string | null = null;
      if (t.electionId) {
        const res = await this.prisma.electionResult.findUnique({ where: { electionId: t.electionId } });
        const winners = (res?.winners as string[] | undefined) ?? [];
        if (winners.length === 1) {
          winningOption = (await this.prisma.electionCandidate.findUnique({ where: { id: winners[0] } }))?.title ?? null;
        }
      }
      result.push({
        id: t.id,
        title: t.title,
        communityName: t.group.name,
        kind: t.kind as unknown as PublicConsensus['kind'],
        conclusion: t.conclusion ?? '',
        objections: t.objections,
        signalCounts: counts,
        closedAt: (t.closedAt ?? new Date(0)).toISOString(),
        winningOption,
      });
    }
    return result;
