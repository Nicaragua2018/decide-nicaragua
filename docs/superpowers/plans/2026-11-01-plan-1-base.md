# Plan 1 — Base: roles, verificación por dos referencias y comunidades

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que una persona invitada se registre eligiendo su territorio de origen y su comunidad de acogida, quede verificada por dos referencias (quien la invitó y el administrador u otro miembro de su territorio o comunidad de acogida), y entonces —y solo entonces— entre a sus dos comunidades; con una mesa directiva de 3 cargos cuyas acciones delicadas requieren 2 de 3.

**Architecture:** Se evoluciona el API NestJS existente (`apps/api`). Tres tablas nuevas en Prisma (`board_seats`, `verification_references`, `board_actions` + `board_approvals`) y un campo nuevo en `profiles` (`current_region`). Dos módulos nuevos: `board` (cargos, guard de la mesa y acciones 2 de 3) y `verification` (referencias). Se ajustan `auth`, `groups` y `users`. La web (`apps/web`, Next.js 15) suma el formulario de comunidad de acogida, el estado de verificación, la página «Verificaciones» y la página «Mesa».

**Tech Stack:** NestJS 10, Prisma 6 + PostgreSQL, vitest 3 (pruebas unitarias con Prisma simulado con `vi.fn()`), Next.js 15 (App Router, server actions), pnpm 9 + Turborepo.

**Spec:** `docs/superpowers/specs/2026-11-01-primeros-200-design.md` (§3 roles, §4 verificación, §5 comunidades).

## Global Constraints

- Las verificaciones solo ocurren por dos referencias: `invitador` (el usuario que invitó, `users.invited_by_id`) + `segunda` (persona distinta: titular del cargo `administrador`, o miembro `verified_citizen` con el mismo `birthDepartment` o la misma comunidad de acogida).
- Excepción de fundación (regla de este plan): mientras haya menos de `BOOTSTRAP_VERIFIED_LIMIT = 4` cuentas `verified_citizen`, una referencia del titular del cargo `administrador` basta para verificar. Queda en la auditoría como `via: "fundacion"`.
- Las membresías de comunidades se crean **solo al verificarse** (`verified_citizen`), nunca al registrarse.
- Un `pending_verification` puede iniciar sesión, pero no participa (no tiene membresías).
- El administrador no puede verificar ni suspender directamente: verificar va por referencias; suspender y cambiar el territorio de origen van por una acción de la mesa con 2 de 3 aprobaciones.
- Límite de invitaciones pendientes por miembro: `MAX_PENDING_INVITES = 5` (el administrador no tiene límite).
- Comunidad activa (puede elegir coordinadores en el plan 3): `MIN_ACTIVE_MEMBERS = 7` miembros verificados.
- Comunidad de acogida: país (ISO 3166-1 alfa-2); en EE. UU., además el estado (código de 2 letras). Slug `country-<cc>` o `country-us-<estado>`.
- Ningún endpoint nuevo devuelve correos ni nombres reales: solo `displayName` del perfil.
- Mensajes de error nuevos en español (los muestra la web tal cual).
- Cada acción nueva escribe un evento de auditoría (`AuditService.log`), sin datos personales en `metadata`.
- Commits con la línea final `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Autoconfirmación o doble referencia de la misma persona (una persona no puede cubrir los dos lugares): debe rechazarse.
2. Segunda referencia de alguien sin relación (otro territorio y otra comunidad de acogida, sin cargo de administrador): debe rechazarse con un mensaje claro.
3. Un `pending_verification` con sesión iniciada intentando proponer, votar o sortear: no debe poder, porque no tiene membresías.
4. Una acción de la mesa aprobada por el mismo cargo dos veces: el segundo voto debe rechazarse; ejecutar requiere 2 personas distintas.
5. Renovación de sesión (`/auth/refresh`) tras 15 minutos: debe conservar `profileId` (hoy lo pierde y rompe grupos y votaciones).

import { HOST_COUNTRIES, US_STATES } from '@decide/shared';

export interface HostCommunity {
  slug: string;
  name: string;
}

/**
 * Comunidad de acogida a partir del país (ISO alfa-2) y, en EE. UU., del estado.
 * Fuera de EE. UU. la región se ignora. Sin país no hay comunidad de acogida.
 */
export function hostCommunity(country: string | null, region: string | null): HostCommunity | null {
  if (!country) return null;
  const cc = country.toUpperCase();
  if (cc === 'US' && region) {
    const rc = region.toUpperCase();
    const state = US_STATES.find((s) => s.code === rc);
    if (state) return { slug: `country-us-${rc.toLowerCase()}`, name: `${state.name}, EE. UU.` };
  }
  const known = HOST_COUNTRIES.find((c) => c.code === cc);
  return { slug: `country-${cc.toLowerCase()}`, name: known ? known.name : cc };
}

type ConHogar = { currentCountry: string | null; currentRegion: string | null };

/** Dos perfiles comparten comunidad de acogida si producen el mismo slug. */
export function sameHostCommunity(a: ConHogar, b: ConHogar): boolean {
  const ha = hostCommunity(a.currentCountry, a.currentRegion);
  const hb = hostCommunity(b.currentCountry, b.currentRegion);
  return ha !== null && hb !== null && ha.slug === hb.slug;
}
```

/**
 * BoardSeat — cargo de la mesa directiva. Un cargo, una persona.
 * Una persona no puede ocupar dos cargos (lo valida BoardService).
 */
model BoardSeat {
  id        String     @id @default(uuid()) @db.Uuid
  role      BoardRole  @unique
  profileId String     @db.Uuid
  profile   Profile    @relation(fields: [profileId], references: [id])
  source    SeatSource
  since     DateTime   @default(now()) @db.Timestamptz

  @@index([profileId])
  @@map("board_seats")
}

/**
 * VerificationReference — una de las dos referencias que verifican a una persona.
 * Una referencia por tipo y una por referente.
 */
model VerificationReference {
  id               String        @id @default(uuid()) @db.Uuid
  subjectUserId    String        @db.Uuid
  subject          User          @relation("ReferencesReceived", fields: [subjectUserId], references: [id], onDelete: Cascade)
  refereeProfileId String        @db.Uuid
  referee          Profile       @relation("ReferencesGiven", fields: [refereeProfileId], references: [id])
  kind             ReferenceKind
  createdAt        DateTime      @default(now()) @db.Timestamptz

  @@unique([subjectUserId, kind])
  @@unique([subjectUserId, refereeProfileId])
  @@index([refereeProfileId])
  @@map("verification_references")
}

/**
 * BoardAction — acción delicada propuesta por un cargo de la mesa.
 * Se ejecuta con 2 aprobaciones de personas distintas; se rechaza con 2 rechazos.
 */
model BoardAction {
  id                  String            @id @default(uuid()) @db.Uuid
  type                BoardActionType
  targetUserId        String            @db.Uuid
  params              Json
  reason              String            @db.VarChar(500)
  status              BoardActionStatus @default(pending)
  proposedByProfileId String            @db.Uuid
  proposedBy          Profile           @relation("BoardActionProposer", fields: [proposedByProfileId], references: [id])
  createdAt           DateTime          @default(now()) @db.Timestamptz
  resolvedAt          DateTime?         @db.Timestamptz

  approvals           BoardApproval[]

  @@index([status])
  @@map("board_actions")
}

model BoardApproval {
  id        String      @id @default(uuid()) @db.Uuid
  actionId  String      @db.Uuid
  action    BoardAction @relation(fields: [actionId], references: [id], onDelete: Cascade)

  profile   Profile     @relation(fields: [profileId], references: [id])
  role      BoardRole
  approve   Boolean
  createdAt DateTime    @default(now()) @db.Timestamptz

  @@unique([actionId, profileId])
  @@map("board_approvals")
}

const VOTOS_PARA_RESOLVER = 2;

@Injectable()
export class BoardService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly audit: AuditService,
    private readonly groups: GroupsService,
  ) {}

  // ─── Cargos ────────────────────────────────────────────────────────────────

  async roleOf(profileId: string): Promise<BoardRole | null> {
    const seat = await this.prisma.boardSeat.findFirst({ where: { profileId } });
    return seat ? (seat.role as BoardRole) : null;
  }

  async isAdministrator(profileId: string): Promise<boolean> {
    return (await this.roleOf(profileId)) === 'administrador';
  }

  async getSeats(): Promise<BoardSeatSummary[]> {
    const seats = await this.prisma.boardSeat.findMany({
      include: { profile: { select: { id: true, displayName: true } } },
    });
    return BOARD_ROLES.map((role) => {
      const s = seats.find((x) => (x.role as string) === role);
      return {
        role,
        holder: s ? { profileId: s.profile.id, displayName: s.profile.displayName } : null,
        source: s ? (s.source as 'fundador' | 'eleccion') : null,
        since: s ? s.since.toISOString() : null,
      };
    });
  }

  /**
   * Arranque (spec §3): el administrador fundador asigna los otros cargos
   * mientras ningún cargo haya salido de una elección.
   */
  async assignFounderSeat(actor: JwtPayload, role: BoardRole, targetProfileId: string, ip: string): Promise<void> {
    const actorRole = actor.profileId ? await this.roleOf(actor.profileId) : null;
    if (actorRole !== 'administrador') {
      throw new ForbiddenException('Solo el administrador puede asignar los cargos fundadores.');
    }
    if ((await this.prisma.boardSeat.count({ where: { source: 'eleccion' } })) > 0) {
      throw new ForbiddenException('Los cargos de la mesa ya se eligen por votación.');
    }
    const target = await this.prisma.profile.findUnique({
      where: { id: targetProfileId },
      include: { user: { select: { status: true } } },
    });
    if (!target || (target.user.status as string) !== 'verified_citizen') {
      throw new BadRequestException('Solo un miembro verificado puede ocupar un cargo.');
    }
    const otroCargo = await this.prisma.boardSeat.findFirst({
      where: { profileId: targetProfileId, NOT: { role } },
    });
    if (otroCargo) throw new BadRequestException('Esa persona ya ocupa otro cargo de la mesa.');

    await this.prisma.boardSeat.upsert({
      where: { role },
      create: { role, profileId: targetProfileId, source: 'fundador' },
      update: { profileId: targetProfileId, source: 'fundador', since: new Date() },
    });

    void this.audit.log({
      actorId: actor.sub,
      action: 'board.seat_assigned',
      resource: `board_seat:${role}`,
      ip,
      metadata: { role, profileId: targetProfileId, source: 'fundador' },
    });
  }

  // ─── Acciones 2 de 3 ──────────────────────────────────────────────────────

  async proposeAction(actor: JwtPayload, dto: ProposeActionDto, ip: string): Promise<{ id: string }> {
    const role = actor.profileId ? await this.roleOf(actor.profileId) : null;
    if (!role) throw new ForbiddenException('Solo la mesa directiva puede proponer esta acción.');

    const target = await this.prisma.user.findUnique({ where: { id: dto.targetUserId } });
    if (!target) throw new NotFoundException('Persona no encontrada');

    if (dto.type === BoardActionType.change_origin) {
      const dept = dto.params['birthDepartment'];
      if (typeof dept !== 'string' || !(NICARAGUA_DEPARTMENTS as readonly string[]).includes(dept)) {
        throw new BadRequestException('Elige uno de los 17 territorios de origen.');
      }
    }

    const action = await this.prisma.boardAction.create({
      data: {
        type: dto.type,
        targetUserId: dto.targetUserId,
        params: dto.params as Prisma.InputJsonValue,
        reason: dto.reason,
        proposedByProfileId: actor.profileId!,
        approvals: { create: { profileId: actor.profileId!, role, approve: true } },
      },
    });

    void this.audit.log({
      actorId: actor.sub,
      action: 'board.action_proposed',
      resource: `board_action:${action.id}`,
      ip,
      metadata: { type: dto.type, targetUserId: dto.targetUserId },
    });
    return { id: action.id };
  }

  async voteAction(actor: JwtPayload, actionId: string, approve: boolean, ip: string): Promise<void> {
    const role = actor.profileId ? await this.roleOf(actor.profileId) : null;
    if (!role) throw new ForbiddenException('Solo la mesa directiva puede votar esta acción.');

    const action = await this.prisma.boardAction.findUnique({
      where: { id: actionId },
      include: { approvals: true },
    });
    if (!action) throw new NotFoundException('Acción no encontrada');
    if ((action.status as string) !== 'pending') throw new BadRequestException('Esta acción ya se resolvió.');
    if (action.approvals.some((a) => a.profileId === actor.profileId)) {
      throw new ConflictException('Ya votaste esta acción.');
    }

    await this.prisma.boardApproval.create({
      data: { actionId, profileId: actor.profileId!, role, approve },
    });

    const votos = [...action.approvals.map((a) => a.approve), approve];
    const aFavor = votos.filter(Boolean).length;
    const enContra = votos.length - aFavor;

    if (aFavor >= VOTOS_PARA_RESOLVER) {
      await this.execute(action.type as unknown as BoardActionType, action.targetUserId, action.params as Record<string, unknown>);
      await this.prisma.boardAction.update({
        where: { id: actionId },
        data: { status: 'executed', resolvedAt: new Date() },
      });
      void this.audit.log({ actorId: actor.sub, action: 'board.action_executed', resource: `board_action:${actionId}`, ip, metadata: { type: action.type } });
    } else if (enContra >= VOTOS_PARA_RESOLVER) {
      await this.prisma.boardAction.update({
        where: { id: actionId },
        data: { status: 'rejected', resolvedAt: new Date() },
      });
      void this.audit.log({ actorId: actor.sub, action: 'board.action_rejected', resource: `board_action:${actionId}`, ip, metadata: { type: action.type } });
    } else {
      void this.audit.log({ actorId: actor.sub, action: 'board.action_voted', resource: `board_action:${actionId}`, ip, metadata: { approve } });
    }
  }

  async listActions(): Promise<BoardActionSummary[]> {
    const actions = await this.prisma.boardAction.findMany({
      orderBy: { createdAt: 'desc' },
      take: 50,
      include: {
        approvals: { select: { role: true, approve: true } },
        proposedBy: { select: { displayName: true } },
      },
    });
    const targets = await Promise.all(
      actions.map((a) => this.prisma.profile.findUnique({ where: { userId: a.targetUserId }, select: { displayName: true } })),
    );
    return actions.map((a, i) => ({
      id: a.id,
      type: a.type as unknown as BoardActionType,
      targetDisplayName: targets[i]?.displayName ?? null,
      params: a.params as Record<string, unknown>,
      reason: a.reason,
      status: a.status as BoardActionSummary['status'],
      proposedBy: a.proposedBy.displayName,
      approvals: a.approvals.map((x) => ({ role: x.role as unknown as BoardRole, approve: x.approve })),
      createdAt: a.createdAt.toISOString(),
    }));
  }

  private async execute(type: BoardActionType, targetUserId: string, params: Record<string, unknown>): Promise<void> {
    if (type === BoardActionType.suspend_user) {
      await this.prisma.user.update({ where: { id: targetUserId }, data: { status: 'suspended' } });
      return;
    }
    const birthDepartment = params['birthDepartment'] as string;
    const profile = await this.prisma.profile.update({
      where: { userId: targetUserId },
      data: { birthDepartment },
    });
    await this.groups.syncMemberships(targetUserId, birthDepartment, profile.currentCountry, profile.currentRegion);
  }
}

import { Reflector } from '@nestjs/core';

import type { BoardRole, JwtPayload } from '@decide/shared';

export const BOARD_ROLES_KEY = 'boardRoles';

/** Restringe a ciertos cargos de la mesa. Sin argumentos: cualquier cargo. */
export const BoardRoles = (...roles: BoardRole[]) => SetMetadata(BOARD_ROLES_KEY, roles);

/** Debe usarse después de JwtAuthGuard: @UseGuards(JwtAuthGuard, BoardGuard) */
@Injectable()
export class BoardGuard implements CanActivate {
  constructor(
    private readonly reflector: Reflector,
    private readonly board: BoardService,
  ) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const roles =
      this.reflector.getAllAndOverride<BoardRole[] | undefined>(BOARD_ROLES_KEY, [
        context.getHandler(),
        context.getClass(),
      ]) ?? [];
    const user = context.switchToHttp().getRequest<Request & { user: JwtPayload }>().user;
    const role = user?.profileId ? await this.board.roleOf(user.profileId) : null;
    if (!role || (roles.length > 0 && !roles.includes(role))) {
      throw new ForbiddenException('Esta sección es solo para la mesa directiva.');
    }
    return true;
  }
}

import {
  BadRequestException,
  ConflictException,
  ForbiddenException,
  Injectable,
  NotFoundException,
} from '@nestjs/common';
import {
  AccountStatus,
  BOOTSTRAP_VERIFIED_LIMIT,
  type JwtPayload,
  type PendingVerification,
  type VerificationStatus,
} from '@decide/shared';
import { PrismaService } from '../prisma/prisma.service';
import { AuditService } from '../audit/audit.service';
import { GroupsService } from '../groups/groups.service';
import { hostCommunity, sameHostCommunity } from '../common/utils/host-community.util';

type Kind = 'invitador' | 'segunda';

@Injectable()
export class VerificationService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly audit: AuditService,
    private readonly groups: GroupsService,
  ) {}

  /**
   * Da una referencia. Con las dos (spec §4) la persona queda verificada y
   * entra a sus comunidades. En la fundación, la del administrador basta.
   */
  async confirm(referee: JwtPayload, subjectUserId: string, ip: string): Promise<void> {
    if ((referee.status as string) !== AccountStatus.verified_citizen || !referee.profileId) {
      throw new ForbiddenException('Solo un miembro verificado puede dar una referencia.');
    }
    if (referee.sub === subjectUserId) throw new BadRequestException('No puedes confirmarte a ti mismo.');

    const subject = await this.prisma.user.findUnique({
      where: { id: subjectUserId },
      include: { profile: true, referencesReceived: true },
    });
    if (!subject || !subject.profile) throw new NotFoundException('Persona no encontrada');
    if ((subject.status as string) !== AccountStatus.pending_verification) {
      throw new BadRequestException('Esta persona no está esperando verificación.');
    }
    if (subject.referencesReceived.some((r) => r.refereeProfileId === referee.profileId)) {
      throw new ConflictException('Ya diste tu referencia a esta persona.');
    }

    const refereeProfile = await this.prisma.profile.findUnique({ where: { id: referee.profileId } });
    if (!refereeProfile) throw new ForbiddenException('Perfil no encontrado');

    const esAdministrador = !!(await this.prisma.boardSeat.findFirst({
      where: { role: 'administrador', profileId: referee.profileId },
    }));
    const verificados = await this.prisma.user.count({ where: { status: 'verified_citizen' } });
    const fundacion = esAdministrador && verificados < BOOTSTRAP_VERIFIED_LIMIT;

    let kind: Kind;
    if (subject.invitedById === referee.sub) {
      kind = 'invitador';
    } else {
      const mismoOrigen =
        !!refereeProfile.birthDepartment && refereeProfile.birthDepartment === subject.profile.birthDepartment;
      if (!esAdministrador && !mismoOrigen && !sameHostCommunity(refereeProfile, subject.profile)) {
        throw new ForbiddenException(
          'La segunda referencia debe darla el administrador o un miembro de su mismo territorio de origen o de su misma comunidad de acogida.',
        );
      }
      kind = 'segunda';
    }
    if (subject.referencesReceived.some((r) => (r.kind as string) === kind)) {
      throw new ConflictException(
        kind === 'invitador' ? 'La referencia de quien invitó ya está dada.' : 'Esta persona ya tiene su segunda referencia.',
      );
    }

    await this.prisma.verificationReference.create({
      data: { subjectUserId, refereeProfileId: referee.profileId, kind },
    });
    void this.audit.log({
      actorId: referee.sub,
      action: 'verification.reference',
      resource: `user:${subjectUserId}`,
      ip,
      metadata: { kind },
    });

    const tipos = new Set<string>([...subject.referencesReceived.map((r) => r.kind as string), kind]);
    if (!(tipos.has('invitador') && tipos.has('segunda')) && !fundacion) return;

    await this.prisma.user.update({ where: { id: subjectUserId }, data: { status: 'verified_citizen' } });
    await this.groups.syncMemberships(
      subjectUserId,
      subject.profile.birthDepartment,
      subject.profile.currentCountry,
      subject.profile.currentRegion,
    );
    void this.audit.log({
      actorId: referee.sub,
      action: 'user.verified',
      resource: `user:${subjectUserId}`,
      ip,
      metadata: { via: fundacion && !(tipos.has('invitador') && tipos.has('segunda')) ? 'fundacion' : 'dos_referencias' },
    });
  }

  /** Lo que ve la propia persona: qué referencias tiene y cuáles faltan. */
  async statusFor(userId: string): Promise<VerificationStatus> {
    const user = await this.prisma.user.findUnique({
      where: { id: userId },
      include: { referencesReceived: { include: { referee: { select: { displayName: true } } } } },
    });
    if (!user) throw new NotFoundException('Persona no encontrada');
    const refs = user.referencesReceived.map((r) => ({
      kind: r.kind as Kind,
      displayName: r.referee.displayName,
    }));
    const missing = (['invitador', 'segunda'] as Kind[]).filter((k) => !refs.some((r) => r.kind === k));
    return { status: user.status as string, references: refs, missing };
  }

  /** Personas pendientes a las que el miembro actual puede dar una referencia. */
  async pendingFor(referee: JwtPayload): Promise<PendingVerification[]> {
    if ((referee.status as string) !== AccountStatus.verified_citizen || !referee.profileId) return [];
    const yo = await this.prisma.profile.findUnique({ where: { id: referee.profileId } });
    if (!yo) return [];
    const esAdministrador = !!(await this.prisma.boardSeat.findFirst({
      where: { role: 'administrador', profileId: referee.profileId },
    }));

    const pendientes = await this.prisma.user.findMany({
      where: { status: 'pending_verification', NOT: { id: referee.sub } },
      include: { profile: true, referencesReceived: true },
      orderBy: { createdAt: 'asc' },
    });

    return pendientes
      .filter((u) => u.profile && !u.referencesReceived.some((r) => r.refereeProfileId === referee.profileId))
      .filter((u) => {
        if (u.invitedById === referee.sub) return !u.referencesReceived.some((r) => (r.kind as string) === 'invitador');
        if (u.referencesReceived.some((r) => (r.kind as string) === 'segunda')) return false;
        const mismoOrigen = !!yo.birthDepartment && yo.birthDepartment === u.profile!.birthDepartment;
        return esAdministrador || mismoOrigen || sameHostCommunity(yo, u.profile!);
      })
      .map((u) => ({
        userId: u.id,
        displayName: u.profile!.displayName,
        birthDepartment: u.profile!.birthDepartment,
        hostCommunity: hostCommunity(u.profile!.currentCountry, u.profile!.currentRegion)?.name ?? null,
        invitedByMe: u.invitedById === referee.sub,
        referencesCount: u.referencesReceived.length,
      }));
  }
}

  const me = meRes.ok ? ((await meRes.json()) as { role: string | null }) : { role: null };
  if (!me.role) return <p className="empty-state">Esta sección es solo para la mesa directiva.</p>;

  const actions = actionsRes.ok ? ((await actionsRes.json()) as BoardActionSummary[]) : [];
  const users = usersRes.ok ? ((await usersRes.json()) as UserListResponse).users : [];
  const noElected = seats.every((s) => s.source !== 'eleccion');

  return (
    <>
      <div className="page-header">
        <h1 className="page-title">Mesa directiva</h1>
        <p className="page-sub">Tres cargos. Las acciones delicadas necesitan la aprobación de 2 de los 3.</p>
      </div>

      {seats.map((s) => (
        <div key={s.role} className="card">
          <p className="card-title">{ROLE_LABEL[s.role]}</p>
          <p className="card-meta">{s.holder ? `${s.holder.displayName} · ${s.source === 'fundador' ? 'fundador' : 'electo'}` : 'Vacante'}</p>
        </div>
      ))}

      {me.role === 'administrador' && noElected && users.length > 0 && (
        <section className="mt-2">
          <h2 className="section-title">Cargos fundadores</h2>
          <p className="text-sm text-muted">Hasta la primera elección, el administrador asigna los otros dos cargos.</p>
          <AssignSeatForm members={users.filter((u) => u.profileId).map((u) => ({ profileId: u.profileId!, displayName: u.displayName ?? '—' }))} />
        </section>
      )}

      {users.length > 0 && (
        <section className="mt-2">
          <h2 className="section-title">Proponer una acción</h2>
          <ProposeActionForm people={users.map((u) => ({ userId: u.id, displayName: u.displayName ?? '—' }))} />
        </section>
      )}

      <section className="mt-2">
        <h2 className="section-title">Acciones</h2>
        {actions.length === 0 && <p className="empty-state">No hay acciones.</p>}
        {actions.map((a) => (
          <div key={a.id} className="card">
            <p className="card-title">
              {a.type === 'suspend_user' ? 'Suspender' : `Cambiar origen a ${String(a.params['birthDepartment'])}`}: {a.targetDisplayName ?? '—'}
            </p>
            <p className="card-meta">
              Propuso {a.proposedBy} · {a.approvals.filter((x) => x.approve).length} a favor ·{' '}
              {a.approvals.filter((x) => !x.approve).length} en contra · {a.status}
            </p>
            <p className="text-sm">{a.reason}</p>
            {a.status === 'pending' && <VoteButtons actionId={a.id} />}
          </div>
        ))}
      </section>
    </>
  );
}
```
